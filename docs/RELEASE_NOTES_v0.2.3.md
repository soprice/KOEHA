# KOEHA v0.2.3

- Floating captions close when Live stops or the audio device stops delivering input. Pending translations can still update the transcript.
- Load and choose translation models in Live using the selected connection profile. The setup cards keep their fields aligned.
- Each translation style saves its system prompt, scene context, and glossary together. Existing shared context and glossaries are copied into the saved styles.
- Translation servers on another computer can use HTTP with an API key. KOEHA warns that the key and text travel unencrypted.

## Windows x64 downloads

- `KOEHA-Setup.exe` installs or upgrades KOEHA. Close KOEHA before upgrading.
- `KOEHA-Windows-x64.zip` is the portable bundle.
- `SHA256SUMS.txt` lists the package checksums. `signature-status.txt` reports the installer's Authenticode status.
